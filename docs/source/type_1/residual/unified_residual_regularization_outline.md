## 2. Shared Preliminaries

This section should be short but precise. It imports the common notation from

### 2.1 Physical Equation

The physical Navier--Stokes equation is

```tex
\partial_t u-\Delta u+(u\cdot\nabla)u+\nabla p=0,
\qquad \nabla\cdot u=0.
```

A finite-energy suitable weak solution satisfies the CKN local energy
inequality, finite global energy, local pressure integrability, and the usual
pressure-gauge convention.

### 2.2 Type I Bound

A terminal singular point `z_*=(x_*,T)` is Type I if

```tex
\limsup_{t\uparrow T}\sqrt{T-t}\,
\|u(\cdot,t)\|_{L^\infty(\mathbb R^3)}<\infty.
```

After shifting and scaling the terminal point, the local ancient variables use
`t<0`.

### 2.3 Centered Variables

For an ancient physical representative `(U,Q)` on
`\mathbb R^3\times(-\infty,0)`, define

```tex
y=\frac{x}{\sqrt{-t}},
\qquad
\tau=-\log(-t),
\qquad
V(y,\tau)=\sqrt{-t}\,U(x,t),
```

and

```tex
\Pi(y,\tau)=(-t)Q(x,t)
```

modulo addition of a function of `\tau`. Then `(V,\Pi)` solves

```tex
\partial_\tau V-\Delta V+\frac12 y\cdot\nabla V+\frac12 V
+(V\cdot\nabla)V+\nabla \Pi=0,
\qquad
\nabla\cdot V=0.
```

The centered equation is the only equation used in the residual branch
arguments.

### 2.4 Normalized Seregin Ancient Limits

A normalized Seregin ancient limit is a smooth bounded solution of the centered
equation generated by the Seregin blow-up construction from a finite-energy
Type I source, with:

```tex
\|V\|_{L^\infty(\mathbb R^3\times\mathbb R)}\le M,
```

local suitability and pressure-gauge control, and a compact cylinder `K` such
that

```tex
\iint_K
\left(|V|^3+|\Pi-c_K(\tau)|^{3/2}\right)\,dy\,d\tau
\ge \eta_0>0.
```

The lower bound is the contradiction target: every residual exclusion ends by
forcing the limiting profile to be zero or to belong to an already removed
class.

### 2.5 Coarse Residual Class

## 3. Section R1: Axisymmetric Bounded-Circulation Residuals

Source: `R1_axisymmetric_bounded_circulation_exclusion.tex`.

### 3.1 Purpose

Exclude the first refined residual class by proving that a bounded centered
angular circulation in an axisymmetric Seregin limit must vanish. The vanishing
of swirl puts the solution into the already removed axisymmetric no-swirl
structured branch.

### 3.2 Definitions

Use cylindrical variables `(rho,theta,Z)` and write

```tex
V=V_\rho e_\rho+V_\theta e_\theta+V_Z e_Z.
```

Define the centered angular circulation

```tex
\Gamma(\rho,Z,\tau):=\rho V_\theta(\rho,Z,\tau).
```

This is scale-invariant:

```tex
rU_\theta(r,z,t)=\rho V_\theta(\rho,Z,\tau),
\qquad
r=\sqrt{-t}\,\rho,\quad z=\sqrt{-t}\,Z.
```

### 3.3 Lemma R1.1: Centered Circulation Equation

If `(V,P)` is a smooth bounded axisymmetric solution of the centered equation,
then `\Gamma` satisfies

```tex
\partial_\tau\Gamma
=
\partial_\rho^2\Gamma-\frac1\rho\partial_\rho\Gamma+\partial_Z^2\Gamma
-\left(V_\rho+\frac\rho2\right)\partial_\rho\Gamma
-\left(V_Z+\frac Z2\right)\partial_Z\Gamma
```

on `(0,\infty)\times\mathbb R\times\mathbb R`, with boundary condition

```tex
\Gamma(0,Z,\tau)=0.
```

Proof ingredients:

1. Write the angular component of the centered equation.
2. Multiply by `\rho`.
3. Use

   ```tex
   \rho\left(\Delta-\frac1{\rho^2}\right)V_\theta
   =
   \partial_\rho^2\Gamma-\frac1\rho\partial_\rho\Gamma+\partial_Z^2\Gamma.
   ```

4. Use the exact cancellation of the `1/2 V_\theta` and drift terms after
   multiplication by `\rho`.
5. Smoothness at the axis gives `V_\theta=O(\rho)` and hence
   `\Gamma=O(\rho^2)`.

### 3.4 Lemma R1.2: Axis-Absorption Liouville Theorem

Let `B=(B_\rho,B_Z)` be bounded and let `G` be a bounded ancient solution of

```tex
\partial_\tau G
=
\partial_\rho^2G-\frac1\rho\partial_\rho G+\partial_Z^2G
-\left(B_\rho+\frac\rho2\right)\partial_\rho G
-\left(B_Z+\frac Z2\right)\partial_ZG
```

on `(0,\infty)\times\mathbb R\times\mathbb R`, with

```tex
\lim_{\rho\downarrow0}G(\rho,Z,\tau)=0
```

locally uniformly. Then `G\equiv0`.

Proof architecture:

1. Set `M_B=\|B\|_\infty`.
2. For `R>1`, define the radial barrier

   ```tex
   h_R(\rho)=
   \frac{\int_0^{\min\{\rho,R\}}s
      \exp(s^2/4-M_Bs)\,ds}
   {\int_0^R s\exp(s^2/4-M_Bs)\,ds}.
   ```

3. Verify

   ```tex
   h_R''+\left(M_B-\frac\rho2-\frac1\rho\right)h_R'=0,
   \qquad h_R'>0.
   ```

4. For the scalar operator `\mathcal L_\tau`, show

   ```tex
   \mathcal L_\tau h_R\le0.
   ```

5. Compare `\pm G/\|G\|_\infty-h_R` in the killed strip
   `(0,R)\times\mathbb R`.
6. Use the killed-strip decay of the Dirichlet heat kernel backward from
   `s\to-\infty`.
7. Obtain

   ```tex
   |G(\rho,Z,t)|\le \|G\|_\infty h_R(\rho).
   ```

8. Let `R\to\infty`; the denominator in `h_R` diverges
   super-exponentially, so `h_R(\rho)\to0` for fixed `\rho`.

### 3.5 Theorem R1: Exclusion of `\mathcal R_1`

If `V\in\mathcal R_1`, then by definition the centered circulation `\Gamma` is
bounded. Apply Lemma R1.2 with `G=\Gamma` and `B=(V_\rho,V_Z)`. Then
`\Gamma\equiv0`, so `V_\theta\equiv0`. The profile is axisymmetric without
swirl, which belongs to a previously removed structured branch. This
contradicts membership in the residual class. Hence

```tex
\mathcal R_1(\mathcal S;I,J)=\varnothing.
```

### 3.6 Remark to Include

The proof is a centered Type I argument. It uses the Ornstein--Uhlenbeck
confining drift in the circulation equation. It does not prove the full
unrenormalized bounded-swirl ancient Liouville theorem.

## 4. Section R2: Rotational Relative Equilibria

Source: `R2_rotational_relative_equilibrium_reduction.tex`.

### 4.1 Purpose

Isolate exactly what is needed to close the rotational relative-equilibrium
class. The class is not closed by simply declaring the rotation skew-adjoint:
the Bernoulli identity contains a constant-vorticity Coriolis term that is not
sign-definite.

### 4.2 Definition: Rotational Relative-Equilibrium Profile

Let `\Omega\in\mathfrak{so}(3)` and

```tex
Q(\tau)=\exp(\tau\Omega).
```

A centered ancient solution is a rotational relative equilibrium if

```tex
V(y,\tau)=Q(\tau)W(Q(\tau)^Ty),
\qquad
P(y,\tau)=\Pi(Q(\tau)^Ty)
```

up to a time-dependent pressure gauge, for a bounded smooth divergence-free
profile `W`.

### 4.3 Lemma R2.1: Co-Rotating Stationary Equation

The profile `(W,\Pi)` satisfies

```tex
-\Delta W+\frac12 y\cdot\nabla W+\frac12 W
+(W\cdot\nabla)W
+\Omega W-(\Omega y)\cdot\nabla W
+\nabla\Pi=0,
\qquad
\nabla\cdot W=0.
```

Equivalently,

```tex
\mathbb P\left[
-\Delta W+\frac12 y\cdot\nabla W+\frac12 W
+(W\cdot\nabla)W
+\Omega W-(\Omega y)\cdot\nabla W
\right]=0.
```

Proof ingredients:

1. Put `z=Q(\tau)^Ty`.
2. Use `Q'=\Omega Q` and `Q^T\Omega Q=\Omega`.
3. Compute `\partial_\tau z=-\Omega z`.
4. Compute

   ```tex
   \partial_\tau V
   =
   Q(\Omega W-(\Omega z)\cdot\nabla W).
   ```

5. Use invariance of `\Delta`, divergence, convection, and pressure gradient
   under rotations.

### 4.4 Input R2.I: Coriolis--Leray Bounded-Profile Liouville Theorem

The residual notes state the exact analytic input:

If `W\in C^\infty\cap L^\infty` is divergence-free and satisfies the projected
Coriolis--Leray profile equation in `\mathbb R^3`, then

```tex
W\equiv0.
```

Equivalent unprojected formulation: every bounded solution is spatially
constant and the whole-space Leray gauge forces the constant to be zero.

This is not optional in the unified paper. It must be:

1. proved in an appendix;
2. imported from a preceding paper; or
3. stated as a named hypothesis exactly as above.

### 4.5 Lemma R2.2: Coriolis Bernoulli Identity

Set

```tex
F(y):=\frac12y-\Omega y,
\qquad
A(y):=W(y)+F(y),
\qquad
\omega:=\nabla\times W.
```

Let `\varpi\in\mathbb R^3` be defined by

```tex
\Omega y=\varpi\times y.
```

Then

```tex
\nabla\times F=-2\varpi.
```

Define

```tex
B:=\frac12|W|^2+\Pi+F\cdot W.
```

Then

```tex
\nabla B+\nabla\times\omega-A\times\omega=0,
```

and

```tex
-\Delta B+A\cdot\nabla B
=
-|\omega|^2-\omega\cdot(\nabla\times F)
=
-|\omega|^2+2\varpi\cdot\omega.
```

Proof ingredients:

1. Use

   ```tex
   (W\cdot\nabla)W
   =
   \nabla\left(\frac12|W|^2\right)-W\times\omega.
   ```

2. Use

   ```tex
   (F\cdot\nabla)W+(\nabla F)^TW
   =
   \nabla(F\cdot W)-F\times\omega.
   ```

3. Since `\nabla\cdot W=0`, replace `-\Delta W` by
   `\nabla\times\omega`.
4. Take divergence of the vector identity and simplify.

### 4.6 Remark: Why Classical NRS Is Not Automatic

For `\Omega=0`, the Bernoulli equation becomes

```tex
-\Delta B+A\cdot\nabla B=-|\omega|^2\le0.
```

For `\Omega\ne0`, the extra term

```tex
2\varpi\cdot\omega
```

has no sign. Thus the usual stationary self-similar Bernoulli maximum-principle
argument does not directly close R2.

### 4.7 Theorem R2: Exclusion of Rotational Relative Equilibria

Assuming Input R2.I, the raw rotational relative-equilibrium residual class is
empty. Indeed:

1. `V` in the class gives a bounded co-rotating profile `W`.
2. Lemma R2.1 puts `W` in the projected Coriolis--Leray equation.
3. Input R2.I gives `W\equiv0`.
4. Hence `V\equiv0`.
5. The inherited positive CKN density of a normalized Seregin limit is
   contradicted.

Therefore

```tex
\mathcal R_2(\mathcal S;I,J)=\varnothing.
```

### 4.8 Proposition R2: Already-Closed Integrable Subcase

If the co-rotating profile satisfies

```tex
W\in L^3(\mathbb R^3),
```

then the physical representative belongs to `L^\infty_tL^3_x`, because
rotations and critical scaling preserve the `L^3` norm. The endpoint theorem
of Escauriaza--Seregin--Sverak, or Albritton--Barker in the ancient mild
formulation, gives `V\equiv0`. Hence the only R2 obligation is the bounded
nonintegrable Coriolis--Leray profile class.

## 5. Section R3: Active Degenerate Stationary-Hull Residuals

Sources:

- `R3_attainability_obligation_closed_by_terminal_stratification.tex`

### 5.1 Purpose

Correct the naive stationary-hull statement. A stationary profile merely
appearing in the time-translation hull is not enough: it may be inactive and
therefore irrelevant to the singularity. The usable residual class requires
active attainment. The stationary branch profile must itself be a Seregin limit
carrying positive local CKN concentration.

### 5.2 Projected Centered Dynamics

Use the projected centered equation

```tex
\partial_\tau V=\mathcal F(V),
\qquad
\mathcal F(W)
:=
\mathbb P\left[
\Delta W-\frac12(W+y\cdot\nabla W)-(W\cdot\nabla)W
\right].
```

### 5.3 Definition: Admissible Stationary Phase Space

An admissible stationary phase space is a Banach space `\mathfrak B` of
solenoidal vector fields satisfying:

1. continuous embedding into
   `C^{2,\alpha}_{\mathrm{loc}}\cap L^\infty`;
2. `\mathcal F` is well-defined on an open set
   `\mathcal U\subset\mathfrak B` and maps into a Banach space
   `\mathfrak Y`;
3. `\mathcal F:\mathcal U\to\mathfrak Y` is `C^1`.

### 5.4 Definition: Nontrivial Stationary Branch

A stationary profile `W` lies on an admissible nontrivial stationary branch if
there is a `C^1` curve `a\mapsto W_a` such that

```tex
W_0=W,
\qquad
\mathcal F(W_a)=0,
```

and the branch is not locally generated only by rigid rotations. Infinitesimally,
the tangent should not lie only in

```tex
\{\Omega W-(\Omega y)\cdot\nabla W:\Omega\in\mathfrak{so}(3)\}.
```

### 5.5 Definition: Local CKN Activity

A stationary profile `(W,\Pi)` is `\varepsilon_*`-active if some compact
parabolic cylinder `Q_r(z_0)` and some pressure gauge `c_{r,z_0}` satisfy

```tex
\iint_{Q_r(z_0)}
\left(|W|^3+|\Pi-c_{r,z_0}|^{3/2}\right)\,dy\,d\tau
\ge \varepsilon_*.
```

### 5.6 Definition: Active Degenerate Stationary-Hull Class

The class `\mathcal R_3^{\mathrm{act}}` consists of residual profiles whose
centered time-translation hull contains a stationary profile `(W,\Pi)` such
that:

1. `W\in\mathfrak B` and `\mathcal F(W)=0`;
2. `W` lies on a nontrivial stationary branch;
3. `(W,\Pi)` is `\varepsilon_*`-active;
4. `(W,\Pi)` is not in previously closed lower classes.

Inactive hull cases must not be closed by the stationary-branch obstruction;
they are routed to the terminal residual class.

### 5.7 Lemma R3.1: Scale Reselection for Hull Limits

If `(V,P)` is a centered Type I Seregin limit from a finite-energy source and

```tex
(V(\cdot,\cdot+s_k),P(\cdot,\cdot+s_k)-c_k(\cdot))
\to (W,\Pi)
```

locally in the Seregin topology, then `(W,\Pi)` is itself a centered Type I
Seregin limit of the same source after reselecting scales.

The adjusted physical scale is

```tex
\lambda_{n,s}=e^{-s/2}\lambda_n.
```

If the hull convergence retains a positive local CKN lower bound, then the new
limit is nontrivial and active.

### 5.8 Lemma R3.2: Stationary Branch Implies Linearized Degeneracy

If `a\mapsto W_a` is a `C^1` stationary branch, then

```tex
D\mathcal F(W_0)\dot W_0=0.
```

If the tangent is nonzero modulo infinitesimal rotations, the linearized
stationary Leray operator has a genuine non-symmetry kernel element.

### 5.9 Lemma R3.3: Branch-Constrained Trajectories Are Stationary

If a solution of the projected centered equation has the form

```tex
V(\tau)=W_{a(\tau)}
```

on a stationary branch, then

```tex
a'(\tau)\dot W_{a(\tau)}
=
\partial_\tau V
=
\mathcal F(W_{a(\tau)})
=0.
```

Where `\dot W_a\ne0`, `a'(\tau)=0`. Thus exact motion along a stationary branch
is stationary.

The later R3 file closes this obligation by terminal stratification.

State the following as an imported theorem from the terminal package.

**Terminal local exclusion package.**  
Let `(U,\Pi)` be a bounded centered Type I Seregin profile satisfying local

```tex
\iint_Q
\left(|U|^3+|\Pi-c_Q(\tau)|^{3/2}\right)\,dy\,d\tau

```

Assume `(U,\Pi)` is outside all previously closed lower classes. Then:

2. scattering, exterior, radiative, and rough alternatives cannot be the sole

   ```tex
   \qquad
   ```

### 5.12 Lemma R3.4: Atomic Carriers Have Backward Sequence-`L^3` Control

This lemma is the covering/contrapositive argument also reused in R4.

Assume a bounded smooth ancient solution is retained active and terminally
atomic: no retained active tail descendant, no radiative descendant, no rough
descendant. If no sequence `\tau_k\to-\infty` has bounded `L^3` norm, then

```tex
\liminf_{\tau\to-\infty}
\|U(\cdot,\tau)\|_{L^3}=\infty.
```

Choose `\tau_n\to-\infty` and `R_n\to\infty` such that

```tex
\int_{|y|>R_n}|U(y,\tau_n)|^3\,dy\ge1.
```

Let

```tex
m_n=
\sup_{|x|>R_n}\int_{B_1(x)}|U(y,\tau_n)|^3\,dy.
```

Then:

1. If `\limsup m_n\ge\varepsilon_*`, some tail camera carries active mass,
   producing either a rough descendant or an active tail descendant.
2. If `m_n<\varepsilon_*` eventually while the exterior mass remains at least
   one, the mass is radiative.

Both contradict atomicity. Therefore a bounded backward sequence of `L^3`
norms exists.

### 5.13 Theorem R3: No Active Stationary Residual Carrier

Let `(W,\Pi)` be stationary:

```tex
-\Delta W+\frac12 y\cdot\nabla W+\frac12 W
+(W\cdot\nabla)W+\nabla\Pi=0,
\qquad \nabla\cdot W=0.
```

Assume `(W,\Pi)` is:

1. a centered Type I Seregin limit;
2. retained active;
3. outside lower classes;
4. subject to the terminal local package.

Then no such `(W,\Pi)` exists.

Proof outline:

1. Apply terminal local exclusion to `(W,\Pi)`.
2. Non-atomic and split alternatives are impossible.
3. The remaining singleton active carrier is terminally atomic.
4. Lemma R3.4 gives `\tau_k\to-\infty` with bounded `L^3` norm.
5. Since `W` is stationary, this implies `W\in L^3(\mathbb R^3)`.
6. Pull back to physical variables:

#### 6.12.1 Time-Synchronized `L^3` Packet Decoupling

Let `f_n:\mathbb R^3\to\mathbb R^3` be a terminal critical sequence with





`B_R(x_{j,n})`, `j\in F`, are disjoint for large `n`, and local strong
convergence gives

```tex
\sum_{j\in F}\int_{B_R}|\Phi_j|^3
\le
\limsup_{n\to\infty}\int_{\mathbb R^3}|f_n|^3
\le M_0^3.
```

Letting `R\to\infty` and then taking the supremum over finite `F` gives


If every retained active profile satisfies


then the active packet is finite and

```tex

\left\lfloor
\frac{M_0^3}{\varepsilon_{\mathrm{sd}}^3}
\right\rfloor.
```

This estimate is valid only for synchronized time slices.
