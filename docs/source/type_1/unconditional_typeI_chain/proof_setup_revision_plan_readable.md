
# Referee-proofing revision plan for `proof_setup.tex`

## Purpose of this memo

This memo gives a detailed revision plan for the setup/reduction paper currently titled:

`Conditional Local Type I Navier--Stokes Reduction: Concentration, Seregin Limits, and Liouville-Class Closures`

The goal is to make the paper clear and referee-proof without changing the strategy and without adding new analytic hypotheses. The recommended changes are mostly structural: make the logical status of each theorem explicit, separate what is proved here from what is imported from the residual-closure companion paper, unify the local/global Type I language, and expand a few proof interfaces that are currently compressed.

The strongest mathematical recommendation is this:

**Make the setup paper formally conditional on the residual closure theorem, and cite Paper IV as the companion result. Do not present residual closure as a theorem proved in this paper unless the full residual proof is included here.**

This does not weaken the strategy. It makes the architecture honest and easier to referee.

## Executive diagnosis

The manuscript has a strong and coherent strategy:

1. obtain local CKN concentration at a terminal singular point;
2. prove or cite the no-escape mechanism needed to keep concentration away from the terminal slice;
3. extract a bounded centered Seregin ancient profile;
4. split possible profiles into explicitly closed Liouville classes plus a residual class;
5. close the uniformly tight class by endpoint \(L^3\) pullback and Albritton--Barker;
6. close structured classes by known axisymmetric and perturbative Liouville theorems;
7. delegate the genuinely residual branch to the companion residual paper.

The paper will become much easier to referee if this dependency chain is made explicit from the title through the final theorem.

The current draft still contains several statements that read unconditional even though they depend on Paper IV. The key examples are:

- `p1:thm:remaining-criterion`, currently titled "Integrated Type I exclusion", states no admissible finite-energy Type I singularity exists.
- `p1:hyp:no-remainder`, currently typed as a theorem, has a proof that says it is the result of the residual analysis.
- `p0:thm:paper0-local-typeI-entry-pipeline` and `p0:cor:paper0-local-typeII-after-bridge` state exclusion "in the completed argument" but are placed in the setup paper as if the proof were internal.
- The introduction says the residual class is kept as a hypothesis, but later theorem statements and prose call the conclusion unconditional.

A referee will not object to a conditional setup paper. They will object to a conditional theorem being presented as proved. The cure is simple: state the residual closure as a named companion theorem or hypothesis, then prove conditional consequences.

## Priority levels

I use the following labels:

**P0: must fix before arXiv or journal submission.** These are issues that can create an immediate referee stop.

**P1: should fix to make proofs airtight.** These changes do not alter the strategy but expand delicate estimates and interfaces.

**P2: presentation and formatting improvements.** These will make the paper easier to read and referee.

## P0 fixes: global logical status

### P0.1 Replace the unconditional main theorem by a conditional theorem

Current issue: the theorem `Integrated Type I exclusion` states:

```tex
\begin{theorem}[Integrated Type I exclusion]
\label{p1:thm:remaining-criterion}
No admissible finite-energy Type I singularity exists.
\end{theorem}
```

This is only true after importing the residual closure theorem from Paper IV. In this setup paper, the theorem should be conditional.

Recommended replacement:

```tex
\begin{theorem}[Conditional Type I exclusion from residual closure]
\label{p1:thm:conditional-typeI-exclusion}
Assume the Residual Closure Theorem \Cref{p1:hyp:no-remainder}
for the class of normalized Seregin limits generated by admissible
finite-energy Type I singularities. Then no admissible finite-energy
Type I singularity exists.
\end{theorem}
```

Then the proof can remain essentially unchanged. The first line should be:

```tex
Assume, toward a contradiction, that \((u,p,z_*)\) is an admissible
finite-energy Type I singularity. By \Cref{p1:thm:extraction}, ...
```

and the final contradiction should explicitly say:

```tex
The residual alternative is impossible by the assumed Residual Closure
Theorem.
```

If Paper IV is public and cited, you can add immediately after the theorem:

```tex
In the companion paper \cite{DuranPaperIV}, \Cref{p1:hyp:no-remainder}
is proved, so the conditional theorem becomes the full Type I exclusion
for the stated admissible class.
```

Do not call the result unconditional in this paper unless that sentence is present and the companion result is actually available.

## P0 fixes: local Type I versus global Type I

### P0.6 Unify the local/global Type I hypotheses

There are currently two Type I notions in the paper.

Part I local pointwise Type I:

```tex
\operatorname*{ess\,sup}_{T-\rho^2<t<T}
\sqrt{T-t}\,\|u(t)\|_{L^\infty(B_\rho(x_*))}\le M .
```

Part II admissible Type I:

```tex
\limsup_{t\uparrow T}\sqrt{T-t}\,
\|u(t)\|_{L^\infty(\R^3)}<\infty .
```

This is a major presentation risk because the title says local Type I, while the extraction theorem is written globally. A PDE referee will ask whether the final exclusion is local or global.

Recommended solution without adding hypotheses:

Create a short subsection titled:

```tex
\subsection{Two equivalent entry points for the setup}
```

Then explain:

1. The extraction estimates in Part II are written for the global pointwise Type I bound to streamline pressure estimates.
2. The local pointwise Type I entry is reduced to the same admissible Seregin extraction by Part I, using the local endpoint weak-Serrin/no-escape mechanism and local pressure-gauge estimates.
3. The final local theorem uses the Part I bridge, not the global bound.

Better yet, rewrite the Part II admissible definition to be local:

```tex
\item there are \(\rho>0\), \(M<\infty\), and \(T_0<T\) such that
\[
  \|u(t)\|_{L^\infty(B_\rho(x_*))}
  \le M(T-t)^{-1/2}
  \qquad T_0<t<T;
\]
```

Then explicitly say that all compact cylinders in the blow-up variables eventually lie inside the physical ball \(B_\rho(x_*)\), while pressure tails are controlled by the finite-energy Leray gauge exactly as in `p0:prop:paper0-local-typeI-terminal-compactness`.

If you do not want to rewrite all Part II estimates locally, then keep Part II global but add a separate theorem:

```tex
\begin{theorem}[Local pointwise Type I entry into the admissible extraction]
...
\end{theorem}
```

and make the final "local Type I" claim use that theorem.

### P0.7 State exactly which theorem converts local pointwise Type I into no-escape

In `p0:cor:paper0-local-typeI-bridge-admissible`, the proof currently says:

```tex
The local weak-Serrin input proves, using the Albritton--Barker weak
Serrin local Type I estimate, that the local pointwise Type I envelope
implies terminal velocity no-escape ...
```

This is too compressed for a central bridge.

Add a formal black-box theorem before this corollary:

```tex
\begin{theorem}[Local endpoint weak-Serrin Type I estimate]
\label{p0:thm:local-weak-serrin-typeI}
Let \((u,p)\) be a finite-energy suitable weak solution near
\(z_*=(x_*,T)\). Assume the local pointwise Type I bound
\[
  \sqrt{T-t}\|u(t)\|_{L^\infty(B_\rho(x_*))}\le M.
\]
Then, after possibly shrinking \(\rho\), the rescaled velocities along
every scale sequence \(r_n\downarrow0\) satisfy
\[
   \lim_{\sigma\downarrow0}\sup_n
   \int_{-\sigma}^{0}\int_{B_1}|u_n|^3\,dx\,dt=0 .
\]
\end{theorem}
```

If this is cited from Albritton--Barker, the proof should be a citation with exact theorem number and a paragraph explaining the match of notation. If you prove it, the proof should derive a scale-invariant \(A\)-bound first and then repeat the interpolation:

\[
\int_{-\sigma}^0\int_{B_1}|u_n|^3
\le
\int_{-\sigma}^0 \|u_n(t)\|_{L^\infty(B_1)}
\int_{B_1}|u_n(t)|^2\,dx\,dt
\le C\sigma^{1/2}.
\]

This theorem is not a new hypothesis; it is the missing formal statement of the estimate already cited.

### P0.8 Separate the global automatic no-escape proof from the local bridge

The section "Automatic No-Escape for Finite-Energy Type I Singularities" proves no-escape under a global pointwise Type I envelope. The later local bridge cites weak-Serrin. These are distinct mechanisms. Make this explicit:

## P1 proof-level improvements: Part I

### P1.1 Strengthen the local concentration statements

The CKN concentration section is logically sound, but it should distinguish three statements:

1. positive \(C+D\) concentration at every singular point;
2. positive velocity-only \(C\) concentration at every singular point;
3. existence of a concentration sequence suitable for extraction.

Right now these are present but spread across several statements. Add a boxed summary proposition:

```tex
\begin{proposition}[Concentration package at a terminal singular point]
Let \(x_*\in\Sigma(T)\). Then:
\begin{enumerate}
\item \(\limsup_{r\downarrow0}(C+D)((x_*,T),r)>0\);
\item \(\limsup_{r\downarrow0}C((x_*,T),r)>0\);
\item if the appropriate no-escape theorem applies, there is an
admissible concentration sequence for the Seregin extraction.
\end{enumerate}
\end{proposition}
```

This consolidates what the setup paper actually uses.

### P1.2 In `p0:prop:compactness-persistence`, remove pressure persistence unless used

The proposition currently requires strong pressure convergence in \(L^{3/2}\). The extraction later only needs velocity nonvanishing. Strong pressure convergence is much harder than strong velocity convergence and is not needed for the \(L^3\) nonzero profile.

Recommended change:

- Either remove the pressure part and state only velocity persistence,
- or move the pressure persistence statement to a remark saying it is not used in the extraction.

Suggested replacement theorem:

```tex
\begin{proposition}[Persistence of velocity concentration]
If \(u_n\to U\) strongly in \(L^3(B_R\times(-R^2,0))\) and
\[
  \int_{-R^2}^{0}\int_{B_R}|u_n|^3\ge\eta,
\]
then
\[
  \int_{-R^2}^{0}\int_{B_R}|U|^3\ge\eta.
\]
\end{proposition}
```

This is cleaner and matches the nontriviality argument in Part II.
